# Проект № 2. Система Робертсона

Задача X.9.7 из второй части практикума. До t = 40 сравниваются RK1–RK4, AB1–AB4, двухстадийный Radau IIA и BDF2. Неявный расчёт также продолжается до контрольных моментов t = 10², 10³, …, 10¹¹.

## Запуск

Python 3.10 или новее.

```bash
python -m pip install -r requirements.txt
python project2.py
```

В `results_project2` появятся четыре рисунка и три таблицы CSV. В `summary.csv` записаны шаги, время остановки и ошибки при t = 40. В `long_horizons.csv` представлены значения на двух сетках и опорное решение в контрольных точках.

Правая часть, якобиан и начальные данные передаются в `ode_methods.py` через `InitialValueProblem`. Обе неявные схемы используют `nonlinear.py` из ЛР3.
